# Java LAN Tic-tac-toe
## Shortcuts:
- Shift + R: Refresh contacts list
- Ctrl + H: Host a game
- Ctrl + C: Connect to IP written in IP box
- Ctrl + 1: Challenge to a game your contact in position 1 (So, your second one)
- Numpad 0-9: Press the respective tile on the board (Except Numpad 5, that one doesn't work. Use numpad 0 instead)
- Ctrl + Enter: Send the currently written message in the text box without deleting it
- Ctrl + R: Reset the board
